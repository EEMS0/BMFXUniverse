# Merchandise integration

The Art & merch section links to `/merch.html`, a same-site page using Shopify's Buy Button collection embed. A standalone document keeps Shopify's cart and event handlers scoped to the shop page instead of the React navigation lifecycle. Relative home and logo links also work in the static preview.

- Store: `rfrjfs-u0.myshopify.com`
- Collection: **EEMS merch**, ID `695390503244`
- Shopify admin: https://admin.shopify.com/store/rfrjfs-u0/collections/695390503244
- Products, variants, prices and availability are loaded live from Shopify.
- The collection initially contains the nine existing active products. Add future products to this collection and make them available to the Buy Button channel.
- The Storefront token in the embed is public, generated by the Buy Button editor. Never replace it with an Admin API token.
- Checkout happens on Shopify; the website does not receive payment details.

## Launch verification

Check mobile and desktop product rendering, colour and size selection, cart totals, and the transition to checkout. Confirm a payment provider is fully activated and that shipping profiles cover the intended destinations. A checkout visit without submitting payment does not verify order fulfillment.

Tapstitch fulfillment settings and billing must be checked in Tapstitch. Preserve its product and variant mapping when editing Shopify products. Confirm fulfillment with an explicitly authorized test order before treating fulfillment as verified.
